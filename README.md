# Currency Converter (Python)

A simple command-line currency converter built using Python.  
The application converts one currency into another using predefined exchange rates.

This project demonstrates basic Python programming, user input handling, and arithmetic logic.

## Features

- Convert between multiple currencies  
- Simple and easy-to-use CLI interface  
- Fast calculations  
- Beginner-friendly project 

## Tech Stack

- Python 3
